# دليل الاستخدام وتعديل المحتوى — الكتالوج الرقمي للدكتورة لبنى كعبية

هذا الكتالوج الرقمي مبني بنظام **البيانات الديناميكية الخفيفة (Data-Driven)** باستخدام HTML وCSS وJavaScript فقط. هذا يعني أنه لا يوجد قاعدة بيانات معقدة ولا تحتاج إلى برمجة لتغيير المحتوى؛ كل تعديلاتك تتم عبر ملفات نصية بسيطة داخل مجلد `docs/assets/js/`.

---

## 1. كيف أغير المعلومات الأساسية (الاسم، الهاتف، WhatsApp، البريد، الروابط)

كل الإعدادات العامة للموقع موجودة في ملف التكوين:
`docs/assets/js/config.js`

افتح الملف وقم بتعديل القيم النصية بين علامتي التنصيص:

```js
window.APP_CONFIG = {
  // وضع الموقع:
  // "review" -> وضع المراجعة (يعرض التنبيهات والأخطاء والمواضيع المسودة والكتالوج القديم)
  // "public" -> وضع النشر العام (يخفي كل بيانات المراجعة والمسودات ويظهر فقط المنشور)
  mode: "review", 

  showPrices: false, // تحويلها لـ true لعرض الأسعار القديمة للجمهور

  // معلومات التواصل:
  phone: "0501234567",       // رقم الهاتف للاتصال المباشر
  whatsapp: "972501234567",  // رقم الواتساب بالصيغة الدولية (بدون أصفار أو رمز +)
  email: "lubna.kaabia@email.com", // البريد الإلكتروني
  instagram: "dr_lubna_kaabia",    // حساب الإنستغرام
  website: "www.lubnakaabia.com"  // الموقع الإلكتروني الإضافي إن وجد
};
```

## 2. كيف أغير تفاصيل برنامج أو ورشة عمل قائمة

المحتوى مقسم على عدة ملفات حسب نوعه:

### أ. البرامج الرئيسية (مثل التوجيه المهني، دعم الإدمان، أم واعية...):
تجدها في ملف: `docs/assets/js/programs.js`
كل برنامج يمثله كائن برمجي (Object). لتعديل اسم، وصف، عدد لقاءات، أو أهداف البرنامج، عدّل الحقول المقابلة:

```js
{
  id: "career-guidance", // المعرف الفريد للرابط (ممنوع تغييره بعد النشر)
  status: "review",      // حالة البرنامج (review لعدم نشره عاماً، أو published لنشره للجمهور)
  title: "برنامج التوجيه المهني للطلاب", // عنوان البرنامج
  audience: ["طلاب الصف الثاني عشر", "المدارس الثانوية"], // الجمهور المستهدف
  meetings: 12,          // عدد اللقاءات (أو null إذا كان غير محدد)
  duration: "ساعتان",     // مدة كل لقاء
  summary: "ملخص قصير يظهر في بطاقة العرض الرئيسية",
  description: "الوصف التفصيلي والكامل للبرنامج..."
  // ... باقي الحقول كالأهداف والجلسات
}
```

### ب. الورش والمحاضرات المفردة (مثل الحصانة النفسية، إدارة المشاعر...):
تجدها في ملف: `docs/assets/js/workshops.js`
يمكنك تعديل حقولها بنفس الأسلوب.

### ج. الكتالوج القديم (Legacy Programs):
تجدها في ملف: `docs/assets/js/legacy-programs.js`

## 4. كيف أحذف برنامجاً من العرض العام دون مسحه نهائياً

إذا أردت إخفاء برنامج معين (أو ورشة) مؤقتًا عن عيون مدراء المدارس والجمهور العام دون حذفه من الكود:
فقط قم بتغيير حالة النشر (`status`) الخاصة بالبرنامج في ملف البيانات إلى:

```js
status: "review"
```

أو:

```js
status: "incomplete"
```

في وضع النشر العام (`mode: "public"` في ملف `config.js`)، سيقوم الموقع تلقائياً بفلترة هذا البرنامج وحجبه عن الظهور تماماً. وعندما ترغب بإعادة إظهاره، قم بإرجاعه إلى:

```js
status: "published"
```

## 5. كيف أنشر الموقع على الإنترنت عبر GitHub Pages

الموقع جاهز تماماً للنشر المجاني والسريع على خدمات استضافة المواقع الثابتة.

### الخطوات التفصيلية للنشر على GitHub Pages:

1. قم بإنشاء مستودع (Repository) جديد على حسابك في GitHub.
2. ارفع كامل ملفات المشروع إلى المستودع.
3. توجه إلى إعدادات المستودع في GitHub واضغط على تبويب **Settings**.
4. من القائمة الجانبية، اختر قسم **Settings -> Pages**.
5. تحت قسم **Build and deployment**:
   - تأكد من اختيار **Deploy from a branch**.
   - اختر الفرع (غالباً `main` أو `master`).
   - **هام جداً:** بجانب اختيار الفرع، ستجد خياراً لتحديد المجلد المصدر. قم بتغييره من `/ (root)` إلى مجلد `/docs`.
6. اضغط على زر **Save**.

خلال دقيقة واحدة، سيقوم GitHub بنشر موقعك وإعطائك رابطاً مباشراً مثل:
`https://username.github.io/repository-name/`

عندما تقوم بتحديث أي محتوى أو تعديل بيانات التواصل، ما عليك سوى إجراء الدفع الاعتيادي للمستودع:
```bash
git add .
git commit -m "تحديث محتوى البرامج وبيانات التواصل"
git push origin main
```
وسيقوم GitHub Pages بتحديث الموقع على الإنترنت تلقائياً خلال ثوانٍ معدودة.

## بيانات يجب تغييرها قبل التسليم النهائي

قبل تسليم الموقع بشكل نهائي للعميل وتفعيله بالكامل، يرجى ضبط الإعدادات الخاصة ببيانات التواصل واستلام الطلبات في ملف الإعدادات الموحد:
[docs/assets/js/config.js](file:///Users/tareksalame/Desktop/Lobna-Website/docs/assets/js/config.js)

لا تحتاج لأي خبرة برمجية للقيام بذلك؛ فقط استبدل القيم النصية الواقعة بين علامات التنصيص بالقيم الصحيحة:

1. **البريد الإلكتروني لاستلام الرسائل (`contactFormEmail`):**
   - استبدل القيمة `"YOUR_EMAIL_HERE"` ببريدك الإلكتروني (مثل: `lubna@example.com`).
   - **ملاحظة هامة بخصوص خدمة FormSubmit:** عند أول إرسال لطلب تواصل عبر النموذج بالموقع، ستصلك رسالة تفعيل تلقائية من خدمة FormSubmit على البريد الإلكتروني الذي حددته. يجب الضغط على الرابط المرفق بها لتأكيد التفعيل وبدء استقبال الطلبات مباشرة.

2. **رقم الواتساب العائم (`whatsapp`):**
   - استبدل القيمة `"YOUR_WHATSAPP_NUMBER"` برقم الهاتف الدولي الخاص بك بشكل متصل وبدون أي مسافات، إشارات جمع (+)، أو شرطات (مثال: `972501234567`).

3. **رابط موقع مدى المطور (`madaWebsite`):**
   - استبدل القيمة `"YOUR_MADA_WEBSITE_URL"` بالرابط الإلكتروني لموقع مدى لتفعيل رابط حقوق التطوير بنجاح.
