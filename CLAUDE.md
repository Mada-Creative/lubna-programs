# Apple Premium Web Design System

You are working inside a project that must follow an Apple-inspired premium web design philosophy.

Do not imitate Apple's surface style.
Do not copy Apple's branding, layouts, colors, typography, or product pages.

Instead, apply the underlying design discipline:
- clarity
- hierarchy
- restraint
- purposeful whitespace
- refined typography
- strong narrative
- brand-specific composition
- purposeful motion
- excellent responsive behavior
- accessibility
- performance
- technical polish

Before writing code:
1. Understand the business.
2. Understand the target audience.
3. Identify the primary page goal.
4. Define the narrative.
5. Define at least one strong visual concept.
6. Only then begin implementation.

Never behave like a generic AI website generator.

Do not default to:
- feature card grids
- SaaS layouts
- random gradients
- glassmorphism
- excessive rounded containers
- generic hero formulas
- meaningless animation
- repeated split sections
- fake statistics
- fake testimonials
- decorative icons without purpose

Every design decision must have a reason.

Before considering a page finished, critically evaluate:
- narrative
- hierarchy
- typography
- composition
- whitespace
- brand specificity
- originality
- mobile quality
- accessibility
- performance
- motion restraint

If any part feels generic or AI-generated, redesign the underlying structure instead of decorating it.
